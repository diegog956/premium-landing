# Premium Landing

Plugin público de Codex para investigar, diseñar, construir, validar y publicar landing pages premium de punta a punta.

## Instalación

```powershell
codex plugin marketplace add diegog956/premium-landing
codex plugin add premium-landing@premium-landing-public
```

Abrí una tarea nueva y ejecutá `$premium-landing`.
